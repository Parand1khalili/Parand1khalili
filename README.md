Alongside research, I build machine-learning applications, explore the fundamentals of AI, and work on data-driven and systems-oriented software projects.

### Research in progress

**A Structure-Aware LLM-Based Framework for Graph Node Labeling** — undergraduate thesis.

Investigating how graph-neighborhood context can inform LLM-assisted node annotation and support label-efficient graph neural network classification. My research interests include **graph ML, LLM–GNN integration, active node classification, and data-efficient learning**.
